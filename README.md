# 🔴 ChangeIt! - Conversor de Divisas Global

Este es mi primer proyecto de 1º de DAM. Es un conversor de moneda profesional que utiliza una API financiera en tiempo real para ofrecer tasas de cambio de más de 160 países.

## 🚀 Características
- **API Real-Time:** Conexión con ExchangeRate-API para obtener precios vivos.
- **Backend PHP:** Procesamiento lógico del lado del servidor.
- **Base de Datos MySQL:** Incluye scripts de creación de tablas y sistema de logs.

## 🛠️ Tecnologías utilizadas
- PHP
- MySQL
- HTML5 y CSS3 (Animaciones personalizadas)
- REST API (JSON)

## 📋 Instalación
1. Clona el repositorio en tu servidor local (XAMPP/LAMP).
2. Ejecuta el script `/sql/setup.sql` en tu base de datos.
3. Renombra `config/db.php.example` a `db.php` y configura tus credenciales.
4. ¡Disfruta convirtiendo divisas!
